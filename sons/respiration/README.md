# Banque « respirations »

Musiques jouées pendant les phases de respirations guidées.

- Dépose ici autant de morceaux que tu veux (MP3 ou M4A de préférence).
- Une piste est tirée au sort à chaque cycle, jamais deux fois la même d'affilée.
- Les morceaux bouclent avec un fondu : leur durée n'a pas d'importance.
- Les noms de fichiers sont libres.

Garde chaque fichier raisonnable (moins de ~15 Mo) : l'iPhone décode le morceau
entier en mémoire.
